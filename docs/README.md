# Project documentation

This directory contains the information needed to build, configure, and maintain
the Veris 8100 ESPHome interface.

## Contents

- [Hardware](hardware/README.md) — components, wiring, DIP switches, manuals,
  schematics, and project photos
- [Software](software/README.md) — ESPHome configuration, credentials, and
  Modbus troubleshooting
- [Modbus register map](software/modbus-registers.md) — transcribed H8163-CB
  register definitions and model notes

Editable mechanical-design files live in [`../hardware/`](../hardware/) rather
than in this documentation directory. General project images are in
[`../images/`](../images/).

When adding documentation, prefer Markdown for project knowledge and retain a
manufacturer PDF when it is the authoritative source or useful offline.
