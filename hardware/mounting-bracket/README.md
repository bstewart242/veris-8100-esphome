# Mounting bracket

Workspace for the planned 3D-printed enclosure or mounting bracket.

## Layout

- `cad/` — editable source models such as STEP, Fusion 360, or FreeCAD files
- `exports/` — printable interchange files such as STL or 3MF
- `drawings/` — dimensioned drawings and assembly references

For each design revision, document the CAD application and version, material,
print orientation, supports, layer height, fasteners, and tested hardware fit.
Generated slicer G-code is intentionally ignored.
